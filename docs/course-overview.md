# 课程目标与路线

核对日期：2026-10-06。

## 总目标

课程最终目标是建立基于多元融合的位置感知系统：传感器产生原始数据，特征与 PDR 提供运动和轨迹信息，融合方法进一步提升定位质量。完整链路是：

```text
手机原始采集 → 数据质检 → 步检 / 步长 / 航向 → PDR 轨迹
                                              ↓
                              KF + 锚点等修正 → 学习方法增强
                                              ↓
                                  实测比较 → 论文 → 答辩
```

课程首页标注总计 32 学时：理论 14、实践 16、考核 2。[来源：课程首页](http://10.112.165.210:9000/multi_source_fusion/)

## 学期路线

| 次数 | 主题 | 阶段成果 / 作用 |
|---|---|---|
| 1 | 绪论与传感器 | 理解传感器、坐标系、噪声、采样和积分漂移；跑通真机监听 |
| 2 | 特征工程 | 滑窗、时域特征、FFT、步频和特征选择 |
| 3–4 | 实验①：采集实践 | 生成采集 App；按协议自采步行数据，质检入库 |
| 5–6 | 惯性导航 PDR | 步检、步长、航向；串接轨迹；第 6 次课发接口及验收口径 |
| 7–8 | 实验②：惯导实践 | Android PDR；第 8 次课末现场演示与报告，形成期中成果 |
| 9–10 | 传统融合与实验③ | 最小二乘、KF；通过 KF 与锚点等修正形成论文基线 |
| 11–12 | 深度学习 | LSTM 残差修正、KalmanNet、轻量化；第 12 次课发论文模板 |
| 13–14 | 实验④：融合实践 | PC / PyTorch 训练修正器；第 14 次课形成 KF 与 DL 对比图及 v2.0 |
| 15–16 | 机动与期末考核 | 第 15 次机动 / 写作指导；第 16 次实测、实验论文与答辩 |

以上是首页路线安排，不是按自然日期生成的排课表。当前尚无足够证据确定各次课的实际日期。[来源：课程首页](http://10.112.165.210:9000/multi_source_fusion/)

## 已明确的考核口径

期中在第 8 次课末：现场演示 40、报告 40、代码规范 20。演示需要 Android 端自采数据、走廊实走 60 秒及实时轨迹投屏；报告和误差口径详见 [验收规范](acceptance.md)。这里的 40/40/20 是期中评分构成，不能直接当作全学期总评权重。[来源：第 6 次课“期中动员”“验收口径”](http://10.112.165.210:9000/multi_source_fusion/lesson04_pdr/slides.html)

首页列出期末三部分分值：现场实测 18、实验论文 16、汇报答辩 6。深度学习实践在 PC 端，CPU 可训；粒子滤波作为延伸自学。不要把这些内容提前扩展为实验①②的必做范围。[来源：课程首页](http://10.112.165.210:9000/multi_source_fusion/)

## 表述约定

- **课程明确要求**：可定位到课件或正式通知，不随项目偏好改变。
- **项目约定**：为了可复现、可靠采集和协作采用的实现或流程，不称为教师硬性要求。
- **建议 / 进阶**：有助于验证或提高质量，但没有足够依据判定必交。
- **待确认**：网站未明确的提交格式、日期、操作流程等；不得自行补成规定。

“已实现”“已自动验证”“已真机验证”“已提交”“已验收”分别记录。打勾需要具体证据，不以完成代码代替完成实验。
